# COLLEGE EVENT MANAGEMENT SYSTEM

Project Type:
C++ Console-Based OOP Project

Project Name:
College Event Management System

Submission Date:
13/10/2026

1. PROJECT PURPOSE
   ==================

The College Event Management System is a console-based C++ application developed using Object-Oriented Programming concepts.

The system is designed to manage college events, participants and event registrations.

The system allows the user to:

* Add event records
* Add participant records
* Display records
* Search event records
* Update event records
* Delete event records
* Register participants for events
* Cancel registrations
* Generate reports
* Save data into files
* Load previously saved data

2. PROJECT OBJECTIVES
   =====================

The main objectives of this project are:

1. To develop a menu-driven College Event Management System.

2. To demonstrate Object-Oriented Programming concepts in C++.

3. To manage event and participant records efficiently.

4. To implement event registration and cancellation.

5. To use dynamic memory allocation.

6. To implement inheritance and runtime polymorphism.

7. To implement file handling and data persistence.

8. To provide Add, Display, Search, Update and Delete operations.

9. To generate a summary report of the system.

10. To develop a complete working C++ console application.

8. CLASS RESPONSIBILITIES

## 4.1 Person

Person is the base class used to demonstrate inheritance and runtime polymorphism.

Main feature:

* Virtual display() function
* Virtual destructor

Person acts as a common base class for Participant and Organizer.

5. CLASS RELATIONSHIPS
   ======================

The major relationships in the system are:

1. Person is the base class of Participant.

2. Person is the base class of Organizer.

3. EventSystem manages Event objects.

4. EventSystem manages Participant objects.

5. EventSystem manages Registration objects.

6. Registration connects a Participant with an Event.

7. EventSystem uses FileManager for saving and loading data.

8. INHERITANCE
   ==============

Inheritance is implemented using the following hierarchy:

```
             Person
            /      \
           /        \
  Participant      Organizer
```

Participant and Organizer are derived classes of Person.

7. RUNTIME POLYMORPHISM
   =======================

Runtime polymorphism is demonstrated using the virtual display() function of the Person class.

Person contains:

```
virtual void display() = 0;
```

Participant and Organizer override the display() function.

The virtual function allows the appropriate derived-class display() function to be selected at runtime.

13. DYNAMIC MEMORY
    =================

Dynamic memory is used in EventSystem.

The following dynamic arrays are created:

```
events = new Event[10];

participants = new Participant[10];

registrations = new Registration[10];
```

The memory is released in the destructor using:

```
delete[] events;
delete[] participants;
delete[] registrations;
```

This prevents memory from remaining allocated after the EventSystem object is destroyed.

# 17. MAIN TRANSACTION

The main transaction of the project is participant registration for an event.

The transaction menu contains:

1. Register Participant for Event

2. Cancel Registration

3. Back to Main Menu

4. EVENT REGISTRATION PROCESS
   ==============================

The registration process is:

1. User enters Registration ID.

2. User enters Event ID.

3. User enters Participant ID.

4. System checks whether the event exists.

5. System checks whether the participant exists.

6. If both records exist, a registration is created.

7. Registration status becomes "Registered".

8. Success message is displayed.

9. REGISTRATION CANCELLATION
   =============================

The user enters the Registration ID.

The system searches for the registration.

If the registration is found:

* Its status is changed to "Cancelled".
* A cancellation message is displayed.

If the registration does not exist:

```
Registration not found!
```

34. IMPORTANT C++ CONCEPTS FOR VIVA
    ===================================

Classes:
A class is a blueprint for creating objects.

Object:
An object is an instance of a class.

Encapsulation:
Data members are kept private and accessed through public functions.

Constructor:
A special function that is automatically called when an object is created.

Destructor:
A special function that is called when an object is destroyed.

Inheritance:
A derived class can acquire properties and functions of a base class.

Polymorphism:
The same function interface can behave differently for different objects.

Virtual Function:
A virtual function allows runtime polymorphism.

Dynamic Memory:
Memory is allocated during runtime using new and released using delete[].

File Handling:
Files are used to permanently store and retrieve data.
